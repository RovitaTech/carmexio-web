# Brand logos

SVG marks from [Simple Icons](https://simpleicons.org) v16.32.0 (CC0-1.0 collection).
Each logo remains a trademark of its owner and is used only to identify the make
of the vehicles Carmexio sells. Mercedes-Benz is not available in Simple Icons
(removed at the brand's request) — the site shows a lettered badge instead.

To add a make: copy `icons/<slug>.svg` from the `simple-icons` npm package here and
register it in `src/app/shared/ui/brand-logo.ts`.
